# Metadata

This directory stores versioned metadata tables used by the analysis.

Expected tables include:

- sample and batch information
- perturbation labels
- guide information
- non-targeting control labels
- cell counts by perturbation and environment
- GEM, batch, sample and donor summaries
- gene identifier mapping
- overlap with the 1,264-task analysis panel

Metadata tables should include a source, generation date, software version and input manifest.
