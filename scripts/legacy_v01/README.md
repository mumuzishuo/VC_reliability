# Legacy internal pilot code

The Python files to be archived here are exact copies from the user's
original `$HOME/VC_reliability/` analysis directory. Preserve their
SHA256 values. They document the retrospective HepG2 pilot and internal
three-context specificity analysis. They are **not** an approved
four-source external prediction pipeline and must not be run against
X-Atlas expression data without a separate, frozen external protocol.

See [method review](../../docs/v01_legacy_method_review.md) for the
bounded code audit and outstanding questions. No raw counts, cell-level
expression files or credentials belong in this directory.
