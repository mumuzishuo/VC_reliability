# Reliability of Virtual Cell Predictions Across Cellular Contexts

虚拟细胞模型跨细胞环境预测的可靠性评价。

## 研究问题

本项目评估模型在来源细胞环境中学习基因扰动响应后，预测未观测目标细胞环境时的可靠性，并研究能否在目标真实响应未知时提前识别高风险任务。

项目重点包括：

- 跨细胞环境扰动响应预测
- OOD 泛化与外部验证
- 零响应基线和简单平均基线
- 预测校准与任务级风险评分
- split-half reproducibility
- batch、GEM、donor、细胞数和扰动强度分层
- 无数据泄漏的可复现评价

## 当前数据

当前包含四个 Perturb-seq 细胞环境：

- K562 essential
- RPE1
- Jurkat
- HepG2

四个环境合计约 966,728 个细胞。当前分析保留了四个环境中每个扰动至少 30 个细胞的 1,264 个扰动任务，并使用四个环境共享的 6,642 个表达基因进行共同空间分析。

## 分析原则

- 原始 count 经过统一的 library-size normalisation。
- 扰动响应使用匹配的 GEM、batch 或 sample 对照计算。
- 所有预测结果都与零响应基线比较。
- 校准参数和风险规则必须在外部目标环境使用前冻结。
- 外部目标环境的真实响应不能用于训练风险评分或选择最有利的方法。
- 每个阶段保存输入、参数、脚本、日志、结果和 SHA256 manifest。

## 目录

- `configs/` 分析参数
- `data/raw/` 原始数据来源和校验信息
- `metadata/` 样本、扰动和基因匹配表
- `scripts/` 可执行分析脚本
- `workflows/` 分析流程说明
- `qc/` 数据质量和审计结果
- `results/` 版本化结果
- `figures/` 图形输出
- `logs/` 运行日志
- `manifests/` 文件清单和 SHA256
- `docs/` 方法、决策和研究记录

原始单细胞矩阵不直接提交到 GitHub。仓库保存数据来源、下载脚本、文件大小和 SHA256 校验值。
