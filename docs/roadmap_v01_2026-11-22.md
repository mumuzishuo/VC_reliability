# VC reliability roadmap v01 — 2026-11-22

This document describes the research milestones, not the number of shell
commands. Repository step 23 is **prepared, not yet executed** as of this
snapshot. Evidence categories must remain separate: author/paper claims,
repository metadata, current-project calculations, and external outcomes.

## Research question

When source contexts predict a gene perturbation response in an unobserved
cellular context, how often does the prediction outperform a zero response,
and can failure be identified before the target response is seen?

The internal four-context results are **development/retrospective evidence**.
A separate, frozen external target is needed for the principal validation.

identify the event D>0; do not promote high MSE correlation or improved
retained-only MSE as proof of successful failure detection. Keep the
prediction-versus-zero decision and its base rate explicit.

derived outputs and SHA256 manifests. Keep downloaded single-cell matrices,
raw metadata and local software packages outside Git. Each external
analysis must use a new versioned output directory and retain its input
hashes. Stage 5 receives a Git tag that points to the frozen protocol.
